## Generated from references

- `src/ForeverSandbox.Server/WorldServer/Network/ForeverUpdateFields.g.cs` is generated by `tools/gen_update_fields.py` from
  `UpdateFields.cpp/.h` of the pinned reference [advocaite/TrinityCore](https://github.com/advocaite/TrinityCore) (GPL-2.0-or-later).
  The generated code reproduces the create-time field order the 1.60.1.70338 client expects.
- `data/hotfixes.json` holds the TACT key and hotfix facts (key bytes and record IDs) that `tools/extract_reference_hotfixes.py`
  reads from the same reference's hotfix SQL.
- The reference files themselves are not included. `tools/Fetch-Reference.ps1` downloads them and checks their hashes.
- Client file formats follow public documentation and readers: [wowdev.wiki](https://wowdev.wiki),
  [WoWDBDefs](https://github.com/wowdev/WoWDBDefs) for table layouts and [CascLib](https://github.com/ladislav-zezula/CascLib)
  for TVFS manifests. No code from them is included.
